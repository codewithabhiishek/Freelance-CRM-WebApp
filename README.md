# Meridian CRM — Client Intelligence Platform

> **Note:** This is a freelance client project developed for enterprise client relationship management and revenue intelligence.

---

## 🌟 Overview

**Meridian CRM** is a modern, high-performance customer relationship management and sales intelligence web application. Built for enterprise account executives, sales teams, and operations managers, it delivers real-time deal tracking, pipeline forecasting, contact intelligence, task management, and comprehensive analytics with zero latency.

---

## ✨ Features

- **📊 Dynamic Executive Dashboard:**
  - Real-time revenue tracking, weighted forecasting, and win-rate indicators.
  - Interactive monthly revenue area charts with target lines and hover inspection.
  - Quick action composer for contacts, deals, and tasks.

- **🗂️ Interactive Sales Pipeline:**
  - Drag-and-drop Kanban board spanning 5 stages (*New Lead*, *Qualified*, *Proposal*, *Negotiation*, *Won*).
  - Instant probability weighting and deal value calculations.
  - Deal editing and detail modals with live status indicators.

- **👥 Contact & Account Intelligence:**
  - Searchable, filterable client roster with status badges (*Lead*, *Customer*, *At Risk*, *Partner*).
  - Detailed slide-out drawer with contact history, private notes, direct call/email actions, and linked deal valuation.

- **📈 Advanced Sales Analytics:**
  - Multi-stage conversion funnels with adaptive gradient visualization.
  - Monthly revenue vs. quota performance comparisons.
  - Team quota leaderboard and touch rhythm heatmaps.

- **✅ Task & Follow-up Management:**
  - Priority-tiered task checklists with completion progress bars and due date filters.

- **🎨 Multi-Theme Engine & Instant Customization:**
  - Dynamic palette switching: **Meridian Pine**, **Cellar Wine**, **Harbor Slate**, and **Foundry Brass**.
  - All SVG charts, sparklines, funnels, buttons, and hover states adapt dynamically to the selected theme via CSS variables.

- **💾 Local-First Persistence:**
  - Full client-side persistence using `localStorage` (`meridian-crm-v1`).
  - One-click JSON data export and demo data reset.

## 🛠️ Tech Stack

- **Framework:** [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite 6](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) + Custom CSS variable token system
- **Icons:** [Lucide React](https://lucide.dev/)
- **Motion & Interactions:** [Framer Motion](https://www.framer.com/motion/) + [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Drag & Drop:** [@dnd-kit](https://dndkit.com/)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Navigate to the project directory:
   ```bash
   cd Freelance/CRM-WebApp
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000/
   ```

### Production Build
To create an optimized production build:
```bash
npm run build
```
